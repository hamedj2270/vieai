# وی - اپلیکیشن مدیریت کارها 🚀

یک اپلیکیشن مدرن و زیبا برای مدیریت کارهای روزمره که با Next.js و TypeScript ساخته شده است.

## ✨ قابلیت‌ها

- 📝 ایجاد، ویرایش و حذف کارها
- ✅ علامت‌گذاری کارها به عنوان انجام شده
- 🎨 طراحی مدرن و واکنش‌گرا
- 🌙 پشتیبانی از حالت تاریک
- ⚡ عملکرد سریع و کارآمد
- 🔒 ذخیره‌سازی داده‌ها

## 🛠️ تکنولوژی‌های استفاده شده

- Next.js
- TypeScript
- Tailwind CSS
- Prisma
- SQLite

## 📱 راهنمای استفاده از اپلیکیشن

1. **ایجاد کار جدید**:
   - روی دکمه "+" در پایین صفحه کلیک کنید
   - عنوان کار را وارد کنید
   - توضیحات اختیاری را اضافه کنید
   - روی دکمه "ذخیره" کلیک کنید

2. **مدیریت کارها**:
   - برای ویرایش یک کار، روی آن کلیک کنید
   - برای حذف کار، روی آیکون سطل زباله کلیک کنید
   - برای علامت‌گذاری به عنوان انجام شده، روی چک‌باکس کلیک کنید

3. **جستجو و فیلتر**:
   - از نوار جستجو برای یافتن کارهای خاص استفاده کنید
   - از فیلترها برای نمایش کارهای انجام شده یا نشده استفاده کنید

4. **تنظیمات**:
   - برای تغییر تم به حالت تاریک، از دکمه تغییر تم استفاده کنید
   - تنظیمات دیگر را از منوی تنظیمات تغییر دهید

## 🚀 شروع کار

1. کپی کردن پروژه:
```bash
git clone https://github.com/YourUsername/vie.git
```

2. نصب وابستگی‌ها:
```bash
cd vie
npm install
```

3. راه‌اندازی پایگاه داده:
```bash
npx prisma migrate dev
```

4. اجرای سرور توسعه:
```bash
npm run dev
```

5. باز کردن [http://localhost:3000](http://localhost:3000) در مرورگر.
